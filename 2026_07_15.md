### Python
<b>1st try:</b>

```python
from collections import deque

def solution(x,y,n):
    queue = deque([(x,0)])
    while queue:
        x,s = queue.popleft()
        if x==y: return s
        elif x>y: continue
        queue.append((x+n,s+1))
        queue.append((x*2,s+1))
        queue.append((x*3,s+1))
    return -1
```
- BFS
- 시간초과

<b>2nd try:</b>

```python
from collections import deque
def solution(x,y,n):
    queue = deque([(y,0)])
    while queue:
        y,s = queue.popleft()
        if x==y: return s
        elif x>y: continue

        if y%3==0: queue.append((y//3,s+1))
        if y%2==0: queue.append((y//2,s+1))
        queue.append((y-n,s+1))
    return -1
```
- BFS지만 x에서 시작하는게 아니라 y에서 시작한다, 이 경우 검색할 경우의 수가 줄어든다. 

### java
```java
import java.util.ArrayDeque;
import java.util.Deque;

class Tuple{
    int y;
    int s;
    Tuple(int y, int s){
        this.y = y;
        this.s = s;
    }
}

class Solution{
    int solution(int x, int y, int n){
        Deque<Tuple> queue = new ArrayDeque<>();
        queue.add(new Tuple(y,0));

        while (!queue.isEmpty()){
            Tuple t = queue.pop();
            int ty = t.y;
            int s = t.s;
            if (x==ty) return s;
            if (x>ty) continue;

            if (ty%3==0) queue.add(new Tuple(ty/3,s+1));
            if (ty%2==0) queue.add(new Tuple(ty/2,s+1));
            queue.add(new Tuple(ty-n,s+1));
        }
        return -1;
    }
}
```
