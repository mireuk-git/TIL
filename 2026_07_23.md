def solution(n,k,enemy):
    i=0
    tmp=[]
    for i in range(len(enemy)):
        tmp.append(enemy[i])
        # use cheat
        if n<enemy[i]:
            if k>0:
                # find the optimal timing
                tmp.sort()
                n+=tmp.pop()
                k-=1
            else: return i
        # progress round
        n-=enemy[i]
        print(tmp, n)
    return i+1
```

def solution(n, k, enemy):
    heap = []

    for i, e in enumerate(enemy):
        heapq.heappush(heap, -e)
        n -= e

        if n < 0:
            if k == 0:
                return i
            k -= 1
            n += -heapq.heappop(heap)

    return len(enemy)
```
- `list` 대신 `heap` 사용, `sort()`할 필요 사라짐
- python에는 최소 힙만 존재하지만, 각 원소의 앞에 `-`를 붙여 최소 힙을 강제로 최대 힙으로 만들 수 있다.
