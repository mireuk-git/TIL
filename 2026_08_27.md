# Codekata
## 주차 요금 계산
[link](https://school.programmers.co.kr/learn/courses/30/lessons/92341)
### python
```python
from math import ceil
# 시간 변환: String->int(min)
def time_convert(time):
    h,m = map(int,time.split(":"))
    return h*60+m

def solution(fees,records):
    info = {} # num:[in,out_bool,time]
    # records 정리
    # 번호판마다 주차 시간 계산
    for record in records:
        time,num,detail = record.split()
        if num not in info.keys(): info[num]=[0,False,0]
        if detail == "IN": #입차 시간 저장
            info[num][0] = time_convert(time)
            info[num][1] = False
        elif detail == "OUT" and num in info.keys(): #출차 처리, 주차 시간 계산
            info[num][1] = True
            info[num][2] += time_convert(time)-info[num][0]
    for i in info.keys(): #출차 하지 않은 차 처리
        if info[i][1]==False:
            info[i][1] = True
            info[i][2] += time_convert("23:59")-info[i][0]
    # 시간 계산
    l = []
    for i in info.keys():
        if info[i][2]>fees[0]:
            fee = fees[1]+ceil((info[i][2]-fees[0])/fees[2])*fees[3]
        else:
            fee = fees[1]
        l.append([i,fee])
    l.sort(key = lambda x: x[0])
    t=[l[i][1] for i in range(len(l))]
    return t
```
- `dict`로 번호판마다 주차 시간 계산
- 마지막에 출차하지 않은 차량은 출차 시간을 "23:59"로 계산
