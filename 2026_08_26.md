## 이진 변환 반복하기

### python
```python
def solution(s):
    string = s
    count = [0,0]
    while string!="1":
        count[0]+=1
        count[1]+=string.count("0")
        string = string.replace("0","")
        string = bin(len(string))[2:]
    return count
```

### java
```java
class Solution{
    public int[] solution(String s){
        int[] count = {0,0};
        String str = s;
        while (!str.equals("1")){
            count[0]++;
            int zero = 0;
            for (int j=0;j<str.length();j++){
                if (str.charAt(j)=='0') zero++;
            }
            count[1]+=zero;
            int l = str.length()-zero;
            String b = "";
            while (l>0){
                b = (l%2)+b;
                l/=2;
            }
            str = b;
        }
        return count;
    }
}
```
