### python
```python
from collections import Counter
def solution(weights):
    weights.sort()
    ratio = [(2,3),(1,2),(3,4)]
    counter = Counter(weights)

    answer=0
    for k in counter.keys():
        # calculate target
        for r in ratio:
            if k%r[0]>0: continue
            target = k*r[1]//r[0]
            answer+=counter[k]*counter[target]
        # 1:1ratio nCr
        answer += counter[k]*(counter[k]-1)//2
    return answer
solution([100,150])
```
- `weights`를 `Counter`화, `weights`는 `Counter`의 헤더로 세트화
- 세트화된 `weights`마다 검색해야 할 헤더 계산
- 계산해야 할 가짓수는 4가지(1:1, 1:2, 3:2, 3:4)
- `Counter`에서 헤더 검색 후 계산 진행

### java
```java
import java.util.HashMap;

class Solution{
    long solution(int[] weights){
        HashMap<Integer,Integer> counter = new HashMap<>();
        for (int w: weights){
            counter.put(w, counter.getOrDefault(w, 0)+1);
        }
        int[][] ratio = {{1,2},{2,3},{3,4}};

        long answer = 0;
        for (int k: counter.keySet()){
            for (int[] r: ratio){
                if (k%r[0]!=0) continue;
                int target = k*r[1]/r[0];
                answer+=(long)counter.get(k)*counter.getOrDefault(target,0);
            }
            answer+=(long)counter.get(k)*(counter.get(k)-1)/2;
        }
        return answer;
    }
}
```
- 100000C2는 int 범위를 넘어선다, `answer`를 long으로 승격시켜야 함
