### python
```python
from itertools import combinations
from collections import Counter

def solution(orders,course):
    l = []
    for c in course:
        # Combination(o,c)
        counter = Counter()
        for o in orders:
            o = sorted(o)
            counter.update(combinations(o,c))
        # 최빈값
        m = 0
        for i in counter.keys():
            if counter[i]>m:
                m = counter[i]
                t = [i]
            elif counter[i]==m:
                t.append(i)
        # 리스트에 추가
        if m>=2:
            for mi in t:
                # String화
                s = ''
                for i in mi: s+=i
                l.append(s)
    l = sorted(list(set(l)))
    return l
```
- `combination()`으로 만들 수 있는 모든 조합의 경우의 수를 생성(oCc)
- `Counter`로 각 값의 나온 횟수 관리
- 최빈값을 `l`에 추가, 같은 빈도의 값이 있다면 `t`에 담아 한번에 처리

### java
```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution{
    public String[] solution(String[] orders, int[] course){
        List<String> l = new ArrayList<>();
        for (int c: course){
            Map<String,Integer> counter = new HashMap<>();
            for (String o: orders){
                char[] chars = o.toCharArray();
                Arrays.sort(chars);
                combination(chars,0,c,"",counter);
            }

            int max = 0;
            List<String> tmp = new ArrayList<>();
            for (String s: counter.keySet()){
                if (counter.get(s)>max){
                    max = counter.get(s);
                    tmp = new ArrayList<>();
                    tmp.add(s);
                }
                else if (counter.get(s)==max){
                    tmp.add(s);
                }
            }

            if (max>=2){
                for (String s: tmp) {
                    if (!l.contains(s)) l.add(s);
                }
            }
        }
        Collections.sort(l);
        String[] r = new String[l.size()];
        for (int i=0;i<l.size();i++) r[i] = l.get(i);
        return r;
    }
    private void combination(char[] arr, int start, int r, String result, Map<String,Integer> counter){
        if (r==0){
            counter.put(result,counter.getOrDefault(result,0)+1);
            return;
        }
        for (int i=start;i<arr.length;i++){
            combination(arr,i+1,r-1,result+arr[i],counter);
        }
    }
}
```
- `combination`이 없어서 스스로 백트래킹을 이용해 구현해야 한다
- `combination`에서 조합을 만듬과 동시에 최대 깊이까지 내려가면 바로 `counter`에 저장
- GPT가 하나의 객체에서 자유로운 수정이 가능한 `StringBuilder`를 이용하는 게 백트래킹상 더 좋다고는 했지만 지금도 충분히 나쁘지 않아보인다
