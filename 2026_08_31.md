### python
```python
def solution(s):
    t = []
    num = ""
    for c in s[1:-1]:
        if c == '{':
            tmp=[]
            open = True
        elif c.isdigit(): num+=c
        elif c == ',' and open:
            tmp.append(int(num))
            num = ""
        elif c == "}":
            if num: 
                tmp.append(int(num))
                num = ""
            t.append(tmp)
            open = False

    t.sort(key=lambda x: len(x))

    result = []
    for i in t:
        e = (set(i)-set(result)).pop()
        result.append(e)
    return result
```
- `t`: 주어지는 표현식 `s`를 리스트로 정리
- `t`를 원소 개수를 기준으로 정렬하면 표현식에 추가되는 원소를 확인할 수 있음, 튜플의 원소 순서를 알 수 있음
- `set`을 통해 추가되는 원소 확인, `result`에 하나씩 순서대로 추가
