# Codekata
## 쿼드압축 후 개수 세기
[link](https://school.programmers.co.kr/learn/courses/30/lessons/68936)
### python
```python
def solution(arr):
    answer = [0,0]

    def quad(x,y,n):
        cur = arr[x][y]
        reduce = True
        for i in range(x,x+n):
            for j in range(y,y+n):
                if arr[i][j]!=cur: 
                    reduce=False
                    break
            if not reduce: break

        if reduce == False:
            half = n//2
            quad(x,y,half)
            quad(x+half,y,half)
            quad(x+half,y+half,half)
            quad(x,y+half,half)
        else: answer[cur]+=1

    quad(0,0,len(arr))
    return answer
```
- dfs식 풀이
- 실제로 `arr`를 바꾸진 않음
- 압축이 가능한 경우 그 영역엔 더이상 연산이 필요하지 않기 때문에 즉시 카운트할 수 있다
- 압축이 불가능할 경우에 그 영역을 4등분해 각각 dfs

### java
```java
class Solution{
    int[] answer = {0,0};
    int[][] arr;
    void quad(int x, int y, int n){
        int cur = arr[x][y];
        boolean reduce = true;
        for (int i=x;i<x+n;i++){
            for (int j=y;j<y+n;j++) {
                if (cur!=arr[i][j]){
                    reduce = false;
                    break;
                }
            }
            if (!reduce) break;
        }
        if (reduce) answer[cur]++;
        else{
            int half = n/2;
            quad(x,y,half);
            quad(x+half,y,half);
            quad(x+half,y+half,half);
            quad(x,y+half,half);
        }
    }
    public int[] solution(int[][] arr){
        this.arr = arr;
        quad(0,0,arr.length);
        return answer;
    }
}
```
- `answer`, `arr`를 `solution`의 속성으로 취급, 재귀함수에 일일히 전달하지 않음
