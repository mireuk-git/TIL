### python
```python
def solution(picks, minerals):
    minerals = minerals[:sum(picks)*5]
    bundled = [[0,0,0] for _ in range(len(minerals)//5+1)]
    for i in range(len(minerals)):
        if minerals[i]=="diamond":
            bundled[i//5][0]+=1
        elif minerals[i]=="iron":
            bundled[i//5][1]+=1
        else: #if minerals[i]=="stone"
            bundled[i//5][2]+=1 
    bundled.sort(key=lambda x:(x[0],x[1],x[2]), reverse=True)

    t=0
    mapping = [[1,1,1],[5,1,1],[25,5,1]] #map[곡괭이][광물]
    for b in bundled:
        for p in range(3):
            if picks[p]>0:
                picks[p]-=1
                for j in range(3):
                    t+=mapping[p][j]*b[j]
                break
    return t
```
- 마지막만 따로 처리하는게 아니라 처음부터 `minerals`의 범위를 제한시켜버리면 간단하게 해결됐음
