def solution(topping):
    left,right = 0,len(topping)
    while (left<right):
        mid = (left+right)//2
        leftset = set(topping[:mid])
        rightset = set(topping[mid:])
        if len(leftset)<len(rightset):
            left = mid+1
        else: right = mid

    i = left
    leftset,rightset = set(topping[:i]),set(topping[i:])
    count = 0
    while len(leftset)==len(rightset):
        count+=1
        i+=1
        leftset = set(topping[:i])
        rightset = set(topping[i:])
    return count
```
- 종류 수 = set
- 이분탐색으로 구간을 나눌 부분을 선별했는데도 시간초과를 피하지 못했다
- 경우의 수를 구하는 구간에서 선형 탐색을 해버려서 생기는 문제인 듯 하다
- 두 구간의 종류 수가 같아지는 왼쪽 끝 구하고 오른쪽 끝 구해야겠네

def solution(topping):
    low,high = 0,len(topping)
    while (low<high):
        mid = (low+high)//2
        leftset = set(topping[:mid])
        rightset = set(topping[mid:])
        if len(leftset)<len(rightset):
            low = mid+1
        else: high = mid
    left = low

    low,high = 0,len(topping)
    while (low<high):
        mid = (low+high)/2
        if mid>int(mid): mid=int(mid)+1
        else: mid = int(mid)
        leftset = set(topping[:mid])
        rightset = set(topping[mid:])
        if len(leftset)>len(rightset):
            high = mid-1
        else: low = mid
    right = high
    
    return right-left+1
```
- 이분탐색 O(logn) * set생성 O(n) = O(nlogn)

### java

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution{
    public int solution(int[] topping){
        Map<Integer,Integer> left = new HashMap<>();
        Set<Integer> right = new HashSet<>();
        int result = 0;
        for (int t: topping) left.put(t,left.getOrDefault(t,0)+1);
        for (int t: topping){
            right.add(t);
            left.put(t, left.get(t)-1);
            if (left.get(t)==0) left.remove(t);

            if (left.keySet().size() == right.size()) result++;
        }
        return result;
    }
}
```
- 왼쪽도막에 모든 토핑을 몰아주고 시작, 사이클마다 원소 하나를 오른쪽으로 전달
- 시간복잡도 O(n)
- 왼쪽도막은 HashMap으로 관리( {topping:중복횟수}), 중복횟수가 0이 되면 왼쪽도막에서 삭제
