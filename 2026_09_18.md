```python
from collections import deque

def solution(relation):
    candidate = [] #찾은 후보키
    c = len(relation)
    r = len(relation[0])
    #bfs
    queue = deque([[i] for i in range(r)])
    while queue:
        i = queue.popleft()
        view = [] # 키집합 i로 생성되는 뷰
        for re in relation:
            v=''
            for j in i:
                v+=re[j]+" "
            view.append(v)
        if len(view)==len(set(view)): #유일성 검사
            if not any(set(c).issubset(i) for c in candidate): #최소성 검사
                candidate.append(i)
        else:#유일성 검사를 통과하지 못하면 다른 속성을 추가해 후보키 확장
            for j in range(i[-1]+1,r):
                queue.append(i+[j]) 
    return len(candidate)
```
- `BFS`로 키 탐색
- 최소성의 성질로 인해 후보키의 속성이 가장 적은 경우부터 탐색(BFS)하면 이미 후보키로 존재하는 속성이 다른 키의 집합에 끼어드는 것을 어느정도 배제할 수 있다.
- BFS가 최소성을 보장해주는 것은 아니라 여전히 최소성 검사가 필요하긴 하다.

```python
from collections import deque

def solution(relation):
    candidate = []
    c = len(relation[0])
    # bfs
    queue=deque([[i] for i in range(c)])
    while queue:
        cols = queue.popleft()
        # 최소성 검사
        if any(set(i)<=set(cols) for i in candidate):
            continue
        # 유일성 검사
        view = [tuple(row[j] for j in cols) for row in relation]
        if len(view)==len(set(view)):
            candidate.append(cols)
        else:
            for j in range(cols[-1]+1,c):
                queue.append(cols+[j])
    return len(candidate)
```

- 뷰를 string으로 만들지 않고 튜플로 만들어 불필요한 변환과정 생략
