### python
```python
def solution(dirs):
    routes = set()
    pos = [0,0]
    for d in dirs:
        route = [tuple(pos)]
        if d == "R":
            if pos[0]<5: pos[0]+=1
            else: continue
        elif d == "L":
            if pos[0]>-5: pos[0]-=1
            else: continue
        elif d == "U":
            if pos[1]<5: pos[1]+=1
            else: continue
        elif d == "D":
            if pos[1]>-5: pos[1]-=1
            else:continue
        route.append(tuple(pos))
        route.sort(key = lambda x: [x[0],x[1]])
        routes.add(str(route))
    return len(routes)
```
- 시작점과 목표점을 연결해 경로 형성, 이때 방향이 없어야 하므로 시작,끝과 관계 없이 항상 좌표가 작은 쪽이 먼저 오도록 정렬
- 경로를 `string` 형태로 저장, `set`으로 중복 제거
- `set`은 `tuple`도 `list`도 받지 않으므로 `string`의 형태로 경로를 저장

### java
```java
import java.util.HashSet;
import java.util.Set;

class Solution{
    public int solution(String dirs){
        Set<String> routes = new HashSet<>();
        int[] pos = {0,0};

        for (char d: dirs.toCharArray()){
            int x = pos[0];
            int y = pos[1];
            switch (d) {
                case 'R' -> {
                    if (pos[0]==5) continue;
                    pos[0]++;
                }
                case 'L' -> {
                    if (pos[0]==-5) continue;
                    pos[0]--;
                }
                case 'U' -> {
                    if (pos[1]==5) continue;
                    pos[1]++;
                }
                case 'D' -> {
                    if (pos[1]==-5) continue;
                    pos[1]--;
                }
            }

            String route;
            if (x<pos[0]||(x==pos[0]&&y<pos[1])){
                route=x+""+y+""+pos[0]+""+pos[1];
            }
            else{
                route=pos[0]+""+pos[1]+""+x+""+y;
            }
            routes.add(route);
        }
        return routes.size();
    }
}
```
