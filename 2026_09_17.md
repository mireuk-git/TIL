# Codekata
## 이모티콘 할인행사
[link](https://school.programmers.co.kr/learn/courses/30/lessons/150368)
### python
```python
def solution(users,emoticons):
    discount = [10,20,30,40]
    n = len(users)
    m = len(emoticons)

    def dfs(rate,d,buy):
        b = buy[:]
        if d>=0:
            for i in range(len(users)):
                if rate>=users[i][0]:
                    b[i] += (100-rate)*emoticons[d]//100
        
        if d<m-1:
            optimal = [0,0]
            for r in discount:
                branch = dfs(r,d+1,b)
                if optimal[0]<branch[0]:
                    optimal=branch
                elif optimal[0]==branch[0] and optimal[1]<branch[1]:
                    optimal=branch
            return optimal
        else:
            subscribe = 0
            for i in range(len(users)):
                if b[i]>=users[i][1]:
                    b[i]=0
                    subscribe+=1
            return [subscribe,sum(b)]

    result = dfs(0,-1,[0]*n)
    return result
```
- 아 구독 조건이 `b[i]>=users[i][1]`인걸 놓쳐서 2시간동안 디버깅만 했네
- `dfs`, `depth=len(emoticons)<=7`, `depth`당 가지수 7가지, O(n)=4**m
- 각 단계에서 사람마다 이모티콘을 구매할지 말지 판정, 총 결제금액(`buy`=`b`)에 합산
- `depth=m-1`에서 구독할 인원 판정, 총 구매 금액 합산
- `subscribe`,`sum(b)` 순으로 우선해 최대값을 리턴
