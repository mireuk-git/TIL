### python
```python
def solution(skill,skill_trees):
    count = 0
    for s in skill_trees:
        i = 0
        avail = True
        for c in s:
            if c in skill:
                if c == skill[i]:
                    i+=1
                else: 
                    avail = False
                    break
        if avail: count+=1
    return count
```
- 검사조건: `skill_tree`에서 `skills`에 있는 문자가 나올때마다 순서를 거스르지 않는지 검사

### java
```java
class Solution{
    public int solution(String skill, String[] skill_trees){
        int count = 0;
        for (String s: skill_trees){
            int lv = 0;
            boolean avail = true;
            for (char c: s.toCharArray()){
                for (int i=0;i<skill.length();i++){
                    if (c == skill.charAt(i)){
                        if (c==skill.charAt(lv)) lv++;
                        else{
                            avail = false;
                            break;
                        }
                    }
                }
                if (!avail) break;
            }
            if (avail) count+=1;
        }
        return count;
    }
}
```
