### python
```python
from math import ceil

def solution(progresses, speeds):
    i = 0
    result = []
    while (i<len(progresses)):
        days = ceil((100-progresses[i])/speeds[i])
        cnt = 1
        i += 1
        while(i<len(progresses) and speeds[i]*days+progresses[i]>=100):
            cnt += 1
            i += 1
        result.append(cnt)
    return result
```
- 기능이 배포될 때에 그 뒤의 프로그램들이 배포할 준비가 됐는지 체크
- 배포 준비가 된 프로그램들은 `cnt`를 올림
- 배포 준비가 되지 않은 프로그램은 즉시 배포 준비의 프로그램들을 배포시킴(`result`에 `cnt` 추가)
### java
```java

import java.util.ArrayList;
import java.util.List;

class Solution{
    public int[] solution(int[] progresses, int[] speeds){
        int iter = 0;
        List<Integer> result = new ArrayList<>();
        while (iter<progresses.length){
            int days = Math.ceilDiv((100-progresses[iter]),speeds[iter]);
            int count = 1;
            iter++;
            while (iter<progresses.length && progresses[iter]+speeds[iter]*days>=100){
                count++;
                iter++;
            }
            result.add(count);
        }
        int[] answer = new int[result.size()];
        for (int i=0;i<result.size();i++) answer[i] = result.get(i);
        return answer;
    }
}
```
- `List`를 primitive type의 array로 변환시키는 거 은근히 귀찮다
