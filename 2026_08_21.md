# Codekata
## 괄호 회전하기
[link](https://school.programmers.co.kr/learn/courses/30/lessons/76502)
### python
```python
def judge(s):
    opening=['(','{','[']
    end={')':'(','}':'{',']':'['}
    stack=[]
    for c in s:
        if c in opening:
            stack.append(c)
        else:
            if len(stack)==0 or end[c] != stack[-1]:
                return False
            stack.pop()
    if len(stack): return False
    return True

def solution(s):
    answer = 0
    for i in range(len(s)):
        string = s[i:]+s[:i]
        if judge(string): answer+=1
    return answer
```
- `judge()`: 올바른 괄호 문자열인지 판정, stack으로 괄호 여는 지점 저장
- `solution()`: 회전 구현
